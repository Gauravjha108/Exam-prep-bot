# 🎓 ExamAce Pro – AI-Powered Study Platform

ExamAce Pro is a cutting-edge, high-performance study platform designed to revolutionize how students prepare for exams. By leveraging Advanced AI (Groq API) and modern web technologies, it provides a personalized, interactive, and visually stunning learning experience.

![ExamAce Pro Banner](https://images.unsplash.com/photo-1434030216411-0b793f4b4173?auto=format&fit=crop&q=80&w=1200)

## 🌟 Key Features

### 🧠 AI-Powered Quiz Generator
Transform any topic or text into comprehensive MCQ assessments. Features instant feedback, detailed explanations, and difficulty level adjustments (Easy, Medium, Hard).

### 🗂️ Dynamic Flashcard System
Memorize complex concepts efficiently with an interactive 3D flashcard interface. AI generates tailored study sets to help you master subjects through active recall.

### 📅 Smart Study Planner
Input your exam dates and topics to receive a scientifically optimized study schedule. It breaks down large subjects into manageable daily goals based on your availability.

### 📝 AI Essay Grader
Get instant, professional-grade feedback on your essays. The AI analyzes structure, grammar, depth of argument, and provides a predicted score alongside improvement tips.

### 💬 AI Tutor (24/7 Chat)
A personal academic assistant available around the clock. Ask complex questions, request summaries, or clarify doubts across any subject.

### 🎭 Premium Aesthetic & UX
- **Warm Industrial Design**: A sleek, editorial-grade dark mode interface.
- **Aurora Visuals**: High-performance WebGL/Canvas backgrounds for a focused study environment.
- **Micro-interactions**: Smooth transitions and glassmorphic elements for a premium feel.

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System), JavaScript (ES6+ Modules)
- **Visuals**: WebGL, Canvas API, OGL Library (Aurora Borealis Effects)
- **Intelligence**: Groq AI API (Llama 3 / Mixtral models)
- **Typography**: Inter, Manrope, and JetBrains Mono (via Google Fonts)

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Edge, or Firefox recommended)
- A Groq API Key (for AI features)

### Setup Instructions
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Gauravjha108/Exam-prep-bot.git
   ```
2. **Configure API Access**:
   - Open `index.html` (or the relevant logic file).
   - Locate the API configuration section.
   - Replace the placeholder with your **Groq API Key**.
3. **Run the Application**:
   - Simply open `index.html` in your browser.
   - For the best experience, use a local server (e.g., Live Server extension in VS Code).
